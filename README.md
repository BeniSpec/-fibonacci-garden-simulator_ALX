# Fibonacci Garden Simulator

Enter a number of days and the program prints how many flowers bloomed
on that day, following the Fibonacci sequence (1, 1, 2, 3, 5, 8, ...).

## Run

Interactive mode:

    python fibonacci_garden.py

Pass the day directly:

    python fibonacci_garden.py 10

## Example

    How many days should the garden grow? 10
    On day 10: 55 flowers bloomed!

## Test

    python -m unittest -v

## Files

- fibonacci_garden.py - the simulator
